# Issue tracker: GitHub

Issues and PRDs for this project live in GitHub Issues in `TH1NKING/leetcode-blind-review`.

## Conventions

- Use the connected GitHub tooling when available.
- When using the `gh` CLI from a directory without this repository's Git remote, always pass `--repo TH1NKING/leetcode-blind-review`.
- Create specifications and work items as GitHub Issues.
- When a skill says to publish a specification, create an Issue and apply the requested workflow label, such as `ready-for-agent`.
- Read an Issue together with its labels and comments before acting on it.
- Add comments for material follow-up decisions instead of silently changing the original request.
- Pull requests are not a request or triage surface for this project.
